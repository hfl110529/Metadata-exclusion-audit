# Experimental data

| Directory | Evidence |
|---|---|
| `upstream_update/` | LlamaIndex two-document fixture, captured embeddings and native stores |
| `backend_updates/` | Two encoders × two backends, native vectors/scores, controls and policy-refresh diagnostic |
| `migration/` | Synthetic identities and three-stage aggregate write/score results |
| `reader_repair/` | Native snapshots, ordinary/target response bodies, paired identities and rank margins |
| `equal_access/` | Matched direct/interval batches and state-binding observations |
| `access_sql/` | PostgreSQL schema/grants, native result rows, query statements, decisions and timings |
| `access_qdrant/` | Qdrant HTTP bodies, identity mapping, route results and API inventory |
| `ehr/` | Authorization and data availability statement only |
| `score_retention/` | Paired scores, contract, independent checkpoints and corruption controls |
| `attribution/` | Target/reference comparison scores, ranks, intervals and reference outcomes |
| `precision/` | Natural/engineered precision views, protocols and RFC source texts |
| `scifact/` | Public source archive, selection, inputs, vectors, responses, scores and transitions |
| `ann/` | HNSW responses, native full-score arrays and recall-bound strata |
| `geometry/` | Public response packet, certificates, analysis and separate nonclinical score oracle |

Files ending in `.gz` use standard gzip compression. Experimental identifiers and hash-bound literals are preserved so observations can be joined and commitments verified. Procedures are in [EXPERIMENTS.md](../EXPERIMENTS.md); expected results are in [RESULTS.md](../RESULTS.md).
